# 卡速售平台对接说明

本说明用于指导接入“卡速售”平台的下单与回调签名规则，确保与系统内置签名实现一致、精炼易读。

一、签名规范（请求侧）
- 签名公式：sign = sha1(Timestamp + SortedJSON(Body) + ApiKey)
- 排序规则：对 Body 的所有键名按 ASCII 码从小到大排序；值按标准 JSON 递归编码（不转义斜杠与中文）。
- 空 Body：当 Body 为空时，参与签名的 JSON 字符串为 "{}"。
- 编码要求：UTF-8。
- 回调地址 url：如作为 Body 字段参与签名，需原样参与（不做 URL 编码）。
- 时间戳：13 位毫秒级字符串（示例：1696645385740）。

示例（仅示意）：
- Body 排序后字符串：{"day":10,"external_orderno":"","ordersn":"D100..."}
- 待签名串：Timestamp + SortedJSON(Body) + ApiKey
- sign：对待签名串做 sha1，结果使用小写十六进制字符串。

二、公共请求头（每次请求必带）
- Sign：上述算法计算得到的签名
- Timestamp：13 位毫秒时间戳（字符串）
- UserId：平台分配的接口 AppId（管理员登录账号）

三、下单接口
- URL：/api/v1/order/buy（示例：http(s)://平台域名/api/v1/order/buy）
- 方法：POST（Content-Type: application/json; charset=utf-8）
- Body 参数：
  - id（int，必填）：商品 ID
  - url（string，选填）：订单回调地址
  - external_orderno（string，必填，建议传唯一值）：三方订单号（防重复）
  - safe_price（string，选填）：安全价格（用于对比，防止调价导致亏损）
  - mark（string，选填）：下单备注
  - quantity（int，必填）：下单数量
  - attach（object，选填）：手工订单模板参数（如不需手工信息可不传）
    - 常见键：recharge_account（充值账号）、lblName1、lblName2 …

- 签名示例（仅示意）：
  Timestamp + {"attach":{...},"external_orderno":"D091...","id":1,"mark":"","quantity":1,"safe_price":"2.2","url":"http://demo.../notify"} + ApiKey

- 返回示例（成功）：
  {"code":200,"msg":"下单成功","data":{"ordersn":"API...","external_orderno":"D091..."}}

四、订单异步回调
- 验证规则：
  1) 取 Body 中的 time 作为 Timestamp；
  2) 从回调参数中移除 sign、card_list、express_list 后，对剩余键按 ASCII 升序并进行稳定 JSON 编码；
  3) 计算 sha1(time + SortedJSON(BodyWithoutExcluded) + ApiKey)，与传入的 sign 比较；
- 回调参数（常见）：
  - external_orderno（string，必填）：外部订单号
  - ordersn（string，必填）：本地订单号
  - status（string，必填）：订单状态
    - 2：正在处理
    - 3：已完成
    - 4：取消交易
    - 5：已退款
  - has_back_money（string，必填）：退款金额
  - total_price（string，必填）：下单金额
  - recharge_hints（string，必填）：订单处理返回信息
  - time（string，必填）：13 位毫秒时间戳
  - sign（string，必填）：签名（小写十六进制）
  - card_list（array，选填，不参与签名）：卡密信息
  - express_list（array，选填，不参与签名）：物流信息
- 状态映射（对接系统内部）：
  - 2 → 充值中（processing）
  - 3 → 成功（success）
  - 4 → 取消（cancelled）
  - 5 → 已退款（refunded）
  - 其他未列出值 → 失败（failed）
- 我方接入的回调地址（供卡速售调用）：
  - URL：POST https://{your_domain}/api/v1/callback/kasushou/{userid}
  - 其中 {userid} 为卡速售平台分配的管理员登录账号（与请求头中的 UserId/系统中的 AccountName 一致），用于定位对应平台账号。
  - 请求头：Content-Type: application/json; charset=utf-8
  - 成功响应：纯文本 "ok"（精确为小写 ok）
  - 示例：POST https://api.example.com/api/v1/callback/kasushou/yourUserId
- 回调响应：返回字符串 "ok" 即为成功。
- 重试机制：若未返回 "ok"，平台将按 5/10/15/20/25 分钟间隔最多回调 5 次。

五、对接提示
- external_orderno 建议传入唯一值，避免重复下单。
- 参与签名的 url 需原样处理，不进行 URL 编码。
- 所有参与签名的数据统一使用 UTF-8 编码。
- 时间戳统一为 13 位毫秒值（字符串）。
- 回调验签务必移除 sign、card_list、express_list 后再参与排序与编码。
