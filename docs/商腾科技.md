# 商腾科技对接规范

平台代号：`shangteng`

接口约定：
- 全局公共参数放在 Header：`ApiKey`、`Sign`、`Timestamp`、`Userid`（通常为秒级字符串；如文档要求毫秒可切换）
- 签名算法：`sha1(Timestamp + SortedJSON(Body) + ApiKey)`，`Sign`为小写十六进制
- SortedJSON(Body)：对业务字段进行 ASCII 升序排序，值递归稳定 JSON 编码（`{}` 用于空对象）

下单接口：
- URL：`{api.URL}/api/Order/create`
- Method：`POST`
- Headers：`Content-Type: application/json; charset=utf-8`、`ApiKey`、`Sign`、`Timestamp`、`Userid`
- Body 字段：
  - `product_id`：商品ID（数字）
  - `recharge_account`：充值账号（手机号等）
  - `external_orderno`：我方订单号
  - `notify_url`：异步回调地址
  - `quantity`：数量，默认 `1`
  - （公共参数放在 Header，不在 Body 中）

回调接口：
- Path：`POST https://{your_domain}/api/v1/callback/shangteng/{userid}`
- `{userid}`：平台分配的管理员登录账号（用于定位我方平台账号）
- 验签：`sha1(time + SortedJSON(postWithoutSign) + ApiKey)`（如需启用）
- 回调参数（示例）：
  - `external_orderno`、`orderno`、`status`、`total_price`、`recharge_hints`、`time`、`sign`
- 状态映射：
  - `1` → 充值中
  - `2` → 成功
  - `3` → 取消
  - `4` → 已退款
  - 其他 → 失败
- 成功响应：纯文本 `ok`

备注：
- 我方实现文件：`internal/service/recharge/shangteng.go`、`pkg/signature/shangteng.go`
- 回调控制器：`internal/controller/callback.go` 的 `HandleShangtengCallback`
- 路由：`/api/v1/callback/shangteng/:userid` 已注册
