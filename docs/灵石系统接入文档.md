## /回调接口参数说明
```text
### 请求方式：POST

以 json 方式提交, content-type=application/json

### 请求参数

如果下单成功，服务器会在处理订单后进行异步回调，将处理结果发至商户指定地址。

商户服务器在接收到回调请求后，须返回success字符串(区分大小写), 平台才会视为回调成功, 其他情况按回调失败执行重试回调的逻辑。

如果一次回调成功，则不会继续回调。
如果回调失败，服务器会在以后几分钟内进行两次重复回调，具体时间视订单处理时间而定。最多三次，如果三次都回调失败，则服务端不会继续回调，此订单被标记为回调失败。

签名示例:

String info = "appId=" + appId
                    + "&code=" + code
                    + "&faceValue=" + faceValue
                    + "&mobile=" + mobile
                    + "&msg=" + msg
                    + "&orderId=" + orderId
                    + "&price=" + price
                    + "&productId=" + productId
                    + "&systemOrderId=" + systemOrderId
                    + "&key=" + this.getChannel().getApikey();
            String verifySing = DigestUtils.md5Hex(info);

```
